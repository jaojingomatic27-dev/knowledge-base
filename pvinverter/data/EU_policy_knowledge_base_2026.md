## 1. 总览：七重政策壁垒

2024-2026年，欧盟对中国新能源企业（储能+光伏）构建了**七重政策壁垒**：

| # | 政策工具 | 生效时间 | 核心目标 | 影响等级 |
|---|---------|---------|---------|---------|
| 1 | **净零工业法案 (NZIA)** | 2025年7月全面实施 | 公共采购排除中国产品，非价格标准限制 | ★★★★★ |
| 2 | **工业加速器法案 (IAA)** | 2026年3月提案，预计2027-2029生效 | "欧洲制造"原产地要求，强制技术转让 | ★★★★★ |
| 3 | **欧盟电池法规 (2023/1542)** | 2023-2028分阶段 | 碳足迹声明/护照/上限，供应链尽职调查 | ★★★★ |
| 4 | **外国补贴条例 (FSR)** | 2023年7月已生效 | 调查中国企业不公平补贴优势 | ★★★★ |
| 5 | **碳边境调节机制 (CBAM)** | 2026年1月正式收费 | 碳成本内部化，削弱中国产品价格优势 | ★★★★ |
| 6 | **光伏临时关税** | 2025年6月 | 对中国光伏组件征收临时关税 | ★★★ |
| 7 | **储能PCS限制** | 2026年5月 | 排除中国PCS获得欧盟公共融资 | ★★★ |

**叠加效果**：三重压力——不在欧洲建厂就系统性失去政府补贴项目资格；建厂则面临强制技术转让、控制权限制和本地化高门槛。

## 2. 净零工业法案 (NZIA)

**全称**: Net-Zero Industry Act
**通过时间**: 2024年4月
**全面实施**: 2025年7月

### 2.1 核心内容

- **2030年目标**：欧盟清洁能源设备40%本土制造
- **"非价格标准"拍卖规则**：2025年12月30日起，至少**30%（或6GW）**的可再生能源拍卖须评估供应链韧性、网络安全和可持续性——不只看价格
- **供应链依赖阈值**：若单一第三国供应>50%某产品类别，欧盟公共采购要求**≥50%价值来自欧盟**，违者罚款最高**合同额10%**

### 2.2 针对中国的具体限制（2025年5月22日C(2025)2900号实施条例）

| 产品类别 | 限制内容 |
|---------|---------|
| **电池储能（通用）** | 最终产品不得在触发国（中国）组装；至少4个主要组件不得来自中国 |
| **陆上风电** | 75%产品价值需非中国来源；最多3个中国组件；齿轮箱等关键部件须本地化 |
| **电解槽** | ≥75%价值来自非中国供应链；数据须在EEA本地化存储 |

**第7(3)条"中国特设条款"**：即使未触发>50%依赖阈值，陆上风电、海上风电和电解槽仍须限制中国内容。

### 2.3 实施时间线（2025年）

| 日期 | 里程碑 |
|------|--------|
| 2025年3月 | 战略项目指南实施法案 |
| 2025年4月 | 公共采购环境可持续性要求 |
| 2025年4月 | 拍卖预审标准 |
| 2025年4月 | 净零技术组件授权法案 |
| 2025年5月23日 | **次级立法发布：非价格标准、依赖阈值、组件清单** |
| 2025年7月 | 法案全面实施 |
| 2025年12月30日 | **非价格标准生效（≥30%可再生能源拍卖）** |

## 3. 工业加速器法案 (IAA)

**全称**: Industrial Accelerator Act
**提案时间**: 2026年3月4日
**状态**: 欧洲议会和理事会审议中（预计约1年立法周期）
**目标**: 2035年制造业占GDP从14.3%提升至20%

### 3.1 电池储能系统 (BESS) 原产地要求

| 阶段 | 要求 |
|------|------|
| **法案生效后1-3年** | BESS须为"欧盟原产"；>1MWh系统BMS须欧盟原产 |
| **法案生效后3年+** | BESS须欧盟原产，**且**电芯+BMS+至少1个其他核心部件须欧盟原产 |

### 3.2 电动车电池要求

| 阶段 | 要求 |
|------|------|
| **生效+6个月** | 车辆在欧盟组装；≥70%欧盟原产（不含电池）；电池≥3个欧盟原产组件（含电芯） |
| **生效+3年** | 电池≥5个欧盟原产组件（电芯、正极活性材料、BMS等）；电驱动系统≥50%欧盟原产 |

### 3.3 外商投资"六选四"强制审查

触发条件：单笔投资**>1亿欧元** + 投资属新兴战略制造领域 + 母国在该领域全球产能占比**>40%**

> ⚠️ 中国光伏和电池制造全球产能占比**>90%**，远超40%门槛，极易触发审查。

须满足6项条件中的**至少4项**（第(e)项**强制**）：

| 条件 | 要求 |
|------|------|
| (a) | 外资持股/表决权≤49% |
| (b) | 须与欧盟企业合资，外资持股≤49%，欧盟方实质参与管理 |
| (c) | **强制向欧盟主体授权核心知识产权**，投资前独立开发的IP归欧盟实体独占 |
| (d) | 每年在欧研发支出≥目标企业年营收的1% |
| (e) 🔒强制 | **欧盟员工占比≥50%**（覆盖所有岗位） |
| (f) | 至少30%的生产投入来自欧盟供应链 |

### 3.4 豁免条款

- 成本差异**>25%**可申请豁免原产地要求
- 项目交付延误**>7个月**可豁免
- 在建/已获许可项目不追溯

### 3.5 公共采购（2029年1月1日起）

- 全部符合条件的采购须用欧盟原产+低碳产品
- **中国不在WTO《政府采购协定》(GPA)中，无欧盟FTA** → 中国企业所有或控制的企业被**系统性地排除**在欧盟特定领域公共采购之外
- 在FTA缔约国（韩国、英国、土耳其等）或GPA缔约国设厂，产品可**视同欧盟原产**

## 4. 欧盟电池法规 (EU 2023/1542)

**生效**: 2023年8月17日
**旧指令废止**: 2025年8月18日
**覆盖范围**: 所有在欧盟市场销售的电池（含储能电池）

### 4.1 实施时间表

| 日期 | 要求 | 涉及产品 |
|------|------|---------|
| 2025年2月18日 | 碳足迹**声明**强制 | 电动车电池 |
| 2025年8月18日 | 旧电池指令废止 | 所有电池 |
| 2026年2月18日 | 碳足迹**性能等级标签** | 工业电池(>2kWh) |
| 2026年8月18日 | 碳足迹等级标签+QR码 | 电动车电池 |
| 2027年2月18日 | **数字电池护照**强制 | EV、LMT、工业电池(>2kWh) |
| 2027年8月18日 | 供应链尽职调查（延后两年） | 年营收>1.5亿欧元企业 |
| 2028年2月18日 | **最大碳阈值**——超标禁售 | 电动车电池 |

### 4.2 三大核心合规支柱

#### 碳足迹（三阶段递进）

1. **声明阶段**：按欧盟PEF方法学生命周期排放核算
2. **等级标签阶段**：A-E等级标签
3. **最大阈值阶段**：超标产品被**禁售**

> ⚠️ **关键挑战**：欧盟**不认可**中国绿证(GEC)。要计入绿电，须证明**额外性**（购电直接推动新增新能源装机）和**时空匹配**（小时级、同电网区域）。否则只能用中国高电网排放因子，可能超2028禁售阈值。

#### 数字电池护照

- 2027年2月18日起强制
- QR码链接，含**64+**强制数据字段
- 三级数据访问：公开（消费者）→限制（回收商）→机密（监管机构）
- ⚠️ **数据出境风险**：护照披露可能触发中国**技术出口管制**（2025年商务部锂电池技术出口限制）

#### 供应链尽职调查

- 延至2027年8月18日（原2025年），门槛提高至**年营收>1.5亿欧元**（原4000万）
- 覆盖钴、锂、镍、天然石墨
- 须遵循OECD尽职调查指南
- 违者罚款：最高**全球年营收的4%**

### 4.3 再生含量要求（2031年起）

| 材料 | 最低再生含量 |
|------|------------|
| 钴 | 16% |
| 锂 | 6% |
| 镍 | 6% |
| 铅 | 85% |

## 5. 外国补贴条例 (FSR)

**生效**: 2023年7月12日
**门槛**: 公共采购合同>2.5亿欧元 + 近三年获≥400万欧元外国财政补贴

### 5.1 2024年关键调查

| 时间 | 事件 | 结果 |
|------|------|------|
| 2024年2月 | 保加利亚列车采购（CRRC中车） | 中企退出，调查终止 |
| 2024年4月3日 | 罗马尼亚110MW太阳能园区（隆基+上海电气） | 两家联合体退出 |
| 2024年4月 | 中国风电供应商（西班牙、希腊、法国、罗马尼亚、保加利亚） | 黎明突袭(Dawn Raids) |
| 2024年4月 | 同方威视（荷兰、波兰办公室） | 扣押电子设备和手机 |
| 2025年12月 | Temu都柏林办公室 | 黎明突袭 |

### 5.2 特征

- "补贴"定义宽泛（远超WTO标准）——CRRC所有政府采购合同被计为"财政资助"（共€75亿）
- 程序不公：极短回复期限（保加利亚案仅3天）
- **事实上的歧视**：2024年三起深入调查全部针对中国企业
- 中国商务部调查结论（2025年1月）：FSR做法**构成贸易投资壁垒**，中国企业直接间接损失约**¥156亿元（€20亿+）**

## 6. 碳边境调节机制 (CBAM)

**过渡期**: 2023年10月–2025年12月（仅申报，不收费）
**正式收费**: 2026年1月1日起
**免费配额取消**: 逐步至2034年完全取消
**扩围计划**: 2028年拟覆盖钢铁/铝密集型下游产品（约180种）

### 6.1 对中国光伏的影响

- 光伏组件本身不直接纳入CBAM，但其**铝边框、钢支架、玻璃**等原材料在CBAM覆盖范围
- 每GW光伏组件碳关税成本：**600–1000万元人民币**（碳价€80/吨）
- 年出口欧盟10GW企业：碳关税**6000万–1亿元**
- 法国碳足迹认证已成为"绿色通行证"，中小企业被拒门外

### 6.2 对中国电池的影响

- 储能集装箱、逆变器机柜等含钢铝产品，预计CBAM扩围后被纳入
- 2025年中国储能海外订单366GWh（+144% YoY），欧洲排第一
- 2026年CBAM正式收费后出口成本显著上升

### 6.3 ESMC推动CBAM扩至光伏下游产品

- **2025年9月**：欧洲太阳能制造委员会(ESMC)正式要求将**光伏组件、支架、跟踪器**纳入CBAM
- 理由：中国组件享受碳成本"免费通行证"
- 目前：欧盟制造商须为进口钢铝购买CBAM证书(~€72-76/吨)，中国成品组件**碳成本为零**

## 7. 关键原材料法案 (CRMA) 与 RESourceEU

**CRMA通过**: 2024年4月 (Regulation (EU) 2024/1252)

### 7.1 2030年目标

| 指标 | 目标 |
|------|------|
| 本土开采 | 10% |
| 本土加工 | 40% |
| 本土回收 | 15% |
| 单一国家依赖上限 | ≤65% |

### 7.2 中国反制与RESourceEU

- **2025年4月4日**：中国限制7种稀土出口（钐、钆、铽、镝、镥、钪、钇）
- **2025年11月8日**：中国扩大限制至锂电池、正负极材料和关键制造设备
- **2025年12月3日**：欧盟推出RESourceEU行动计划
  - 动员**€30亿**用于关键矿产
  - 2029年前将对单一外国供应商依赖削减**30-50%**
  - 限制废旧电池材料（黑粉）和磁铁废料出口
  - 快速审批：开采27个月，加工/回收15个月
  - 2026年成立欧洲关键原材料中心（投资、储备、联合采购）
  - 2026年开始关键矿产**储备**

### 7.3 关键数据

- 中国控制全球稀土精炼能力**90%+**、稀土开采**~70%**
- 中国控制全球关键矿产加工能力**81%**、电池组件生产**60%**
- 欧盟95%的稀土进口仅来自3国：中国、马来西亚、俄罗斯
- 欧盟93%的风电永磁体来自中国

## 8. 光伏临时关税

- **2025年6月23日零时**起，欧盟对**原产于中国的光伏组件**实施临时关税
- 政策矛盾：欧盟产组件比中国贵**35-40%**
- 德国测算：全部用本地组件，光伏发电成本从€0.06/kWh升至€0.09/kWh，2030年目标额外成本**€240亿**
- 2024年欧盟占中国组件出口**23%**(~65GW)
- 临时关税可能导致2025年中国对欧出口下降**15-20%**

## 9. 储能PCS公共资金限制

**时间**: 2026年5月

欧盟委员会将对"高风险国家"逆变器公共资金限制从光伏、风电正式**扩展至储能PCS（储能变流器）**：

- 欧洲投资银行(EIB)、欧洲投资基金(EIF)等**核心融资渠道不得为使用中国PCS的项目提供资金**
- 实际效果：欧盟公共融资项目**直接排除中国PCS产品**
- 官方理由："国家安全"和"供应链自主"
- 受影响：中国2025年海外储能订单欧洲第一约61.82GWh

## 10. 中国企业影响评估

### 10.1 量化影响估算

| 指标 | 数据 |
|------|------|
| 光伏组件碳关税成本 | 600–1000万元/GW（€80/t碳价） |
| 海外新能源项目IRR下降 | 2-5个百分点 |
| PCS公共资金项目直接损失 | 约61.82GWh订单面临排除风险 |
| FSR调查中国企业损失 | ¥156亿元（€20亿+） |
| 光伏对欧出口预测下降 | 15-20%（2025年） |

### 10.2 头部企业欧洲布局现状

| 企业 | 欧洲基地 | 产能 | 状态 |
|------|---------|------|------|
| **宁德时代 (CATL)** | 匈牙利德布勒森 + 西班牙萨拉戈萨(JV Stellantis) | 100GWh + 50GWh | 匈牙利一期2025年底投产，二期暂停 |
| **比亚迪 (BYD)** | 匈牙利塞格德（整车）+ 电池工厂评估中 | 50万辆/年 | 整车厂2025年底完工；电池厂尚未决策 |
| **亿纬锂能 (EVE)** | 匈牙利德布勒森 | 28GWh | 目标2026/2027 |
| **国轩高科 (Gotion)** | 德国哥廷根 + 斯洛伐克 | ~20GWh | 运营中 |
| **中航锂电 (CALB)** | 葡萄牙锡尼什 | 15GWh | ~€20亿投资，目标2027/2028 |
| **隆基绿能 (LONGi)** | 德国 | - | 已获法国碳足迹认证 |

### 10.3 关键风险

1. **电芯+BMS原产地要求（IAA）**：3年后须欧盟原产，中国厂商须在欧建电芯厂
2. **强制技术转让**：IAA第(c)条要求核心IP授权给欧盟实体
3. **49%持股上限**：外商投资审查强制条件
4. **碳足迹认证壁垒**：中国绿证不被认可，可能超2028年禁售阈值
5. **PCS公共融资排除**：中国PCS在欧盟公共项目直接出局
6. **数据本地化**：BMS运行数据须存EEA，与中国数据法规存在冲突
7. **中国出口管制反制**：锂电池技术2025年起受出口许可限制，海外建厂所需技术输出受阻

### 10.4 欧洲电动车需求放缓的连锁影响

- 匈牙利电池产量2024年12月同比**-51%**
- 三星SDI匈牙利工厂裁员并暂时关闭
- **Northvolt破产**（2025年3月）：欧洲"电池冠军"倒下
- 欧洲电网大停电（2025年4月，~6000万人受影响）→反而凸显中国储能技术需求

## 11. 中国企业应对策略

### 策略一：本地化深度布局

- 头部企业：匈牙利/东欧建厂，本地化率30-50%+，逐步提升至满足IAA要求
- 利用IAA豁免：成本差异>25%可申请豁免原产地要求
- FTA/GP缔约国设厂：产品视同欧盟原产（韩国、英国、土耳其等）

### 策略二：碳足迹合规

- 立即按欧盟**PEF方法论**（非中国国内标准）收集碳足迹数据
- 重构电力采购：优先实体PPA或直接可再生能源（满足额外性和时空匹配要求）
- 区块链溯源系统（如Catena-X兼容）
- 预约欧盟认可的合格评定机构(CAB)进行预审

### 策略三：技术授权+运营主导权

- 以财务投资人角色参与特定项目，保留关键运营主导权
- 合资架构设计：外资持股≤49%但通过协议保留上游采购和技术迭代主导权
- 对核心技术分类管理，严格限制前沿技术授权

### 策略四：市场多元化

- 重点拓展东南亚、中东、拉美、非洲、中亚
- 利用"一带一路"产能合作规避壁垒

### 策略五：合规前置

- 建立全维度风险预警机制（地缘、价格、产能、交付、库存）
- 协议加入法律稳定性条款、不可抗力条款、补偿及退出机制
- 合同修订：供应商ESG合规条款及违约责任
