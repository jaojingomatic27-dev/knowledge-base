# 笔记 2/10：NZIA 净零工业法案

## 封面设计

```
┌─────────────────────────┐

│  2024年4月通过           │
│  2025年7月全面实施        │
│  ━━━━━━━━━━━━━━━━━━━━━  │
│  核心杀招：              │
│  ❌ 中国产品不能参加      │
│     欧盟政府项目招标      │
│  ❌ 可再生能源拍卖        │
│     不再只看价格          │
│  ❌ 中国储能至少4个组件   │
│     不得来自中国          │
│  ━━━━━━━━━━━━━━━━━━━━━  │
│  2025.12.30 生效         │
└─────────────────────────┘
```

## 正文

NZIA 全称 Net-Zero Industry Act，表面上是推欧盟本土清洁能源制造。

实际杀招有三个👇

**① "非价格标准"拍卖规则**
2025年12月30日起，至少30%（或6GW）的可再生能源拍卖，不只看价格了。
要看：供应链韧性、网络安全、可持续性。
——翻译一下：你的产品是中国供应链来的？扣分。

**② 供应链依赖阈值**
如果任何一个第三国供应>50%某产品 → 欧盟公共采购要求≥50%价值来自欧盟。
罚金：合同额的10%

**③ 中国特设条款（第7(3)条）**
即使没触发50%阈值，陆上风电、海上风电和电解槽也必须限制中国内容。
电池储能：**最终产品不得在中国组装，至少4个主要组件不得来自中国。**

⚡ 说白了：用规则把中国产品从欧盟政府项目中排出去。

**IAA（Industrial Accelerator Act）**，2026年3月4日提案，正在审议中。
目标：2035年制造业占GDP从14.3%提到20%。

看一下对储能产品的要求👇

⚠️ 注意：目前全球电芯产能中国占90%+。欧盟基本上没有规模化电芯产能。

这意味着什么？
**如果你不在欧洲建电芯厂 —— 3年后你的产品就进不来了。**

# 笔记 4/10：IAA 工业加速器法案（下）—— 六选四

## 封面设计

```
┌─────────────────────────┐
│  🔒 IAA "六选四"审查     │
│                         │
│  想在欧洲建电池厂？      │
│  必须接受这6条中的4条：  │
│                         │
│  ☑ 持股≤49%             │
│  ☑ 与欧盟企业合资        │
│  ☑ 强制授权核心IP        │
│  ☑ 年研发≥营收1%         │
│  🔒 欧盟员工≥50%（强制）  │
│  ☑ 30%本土采购           │
│                         │
│  ⚠️ 触发即强制           │
└─────────────────────────┘
```

## 正文

接上篇。IAA还有一个更可怕的机制——外商投资"六选四"审查。

**什么时候触发？**
- 单笔投资 >1亿欧元
- 属于新兴战略制造领域
- 母国在该领域全球产能占比 >40%

⚠️ 中国光伏和电池制造全球占比 **>90%**，远超门槛。必中。

**触发后，须满足以下6条中的至少4条**（第⑤条强制）：

① 外资持股/表决权 ≤ 49%
② 须与欧盟企业合资，欧盟方实质参与管理
③ **强制向欧盟实体授权核心知识产权**（投前独立开发的IP归欧盟实体独占）
④ 每年在欧研发支出 ≥ 目标企业年营收的1%
⑤ 🔒 **欧盟员工占比 ≥ 50%**（强制！所有岗位）
⑥ 至少30%的生产投入来自欧盟供应链

👇 重点看第③条：

**你的核心技术，要白送给欧盟实体。**

这是前所未有的条款。不是"技术合作"，不是"合资"，是**单方面强制授权**。

豁免要满足：成本差异>25% / 项目延误>7个月 / 在建项目不追溯。

# 笔记 5/10：欧盟电池法规 —— 碳足迹+数字护照

## 封面设计

```
┌─────────────────────────┐
│  🔋 电池法规 2023/1542   │
│                         │
│  2027 → 数字电池护照     │
│  2028 → 碳超标直接禁售   │
│  2031 → 再生含量强制     │
│                         │
│  ⚠️ 欧盟不认可中国绿证   │
│  你的绿电可能不算"绿"    │
└─────────────────────────┘
```

## 正文

欧盟电池法规是最早动手的——2023年就生效了，分阶段推进。

**关键时间节点：**

📅 **2025.2** — 电动车电池碳足迹声明强制
📅 **2026.2** — 工业电池（>2kWh）碳足迹等级标签
📅 **2027.2** — **数字电池护照强制**（64+数据字段，QR码）
📅 **2027.8** — 供应链尽职调查（钴/锂/镍/石墨溯源到矿）
📅 **2028.2** — **最大碳阈值——超标产品禁售**
📅 **2031** — 最低再生含量（钴16% 锂6% 镍6% 铅85%）

**最大的坑在哪？**

欧盟**不认可**中国绿证(GEC)。
你要证明你的绿电：
- 额外性：购电直接推动新增新能源装机
- 时空匹配：小时级、同电网区域

没这个 → 只能用中国高电网排放因子 → **可能直接超2028禁售阈值**。

罚款：**全球年营收的4%**。

💡 对策：尽早按欧盟PEF方法论（非国内标准）收集碳数据；重签PPA；找欧盟CAB机构预审。

# 笔记 6/10：FSR + 光伏关税 —— 贸易打击

## 封面设计

```

│  ⚡ FSR + 关税双杀       │
│                         │
│  2024年三起调查          │
│  全部针对中国企业        │
│                         │
│  中国企业累计损失        │
│  ¥156亿（€20亿+）       │
│                         │
│  光伏关税 2025.6.23 生效 │
│  对欧出口预计 ↓15-20%   │
└─────────────────────────┘
```

## 正文

**FSR（外国补贴条例）** 是欧盟2023年7月推出的工具。

门槛很低：公共采购>2.5亿欧元 + 3年内获≥400万欧元外国补贴 → 必报。

2024年真实案件👇

| 时间 | 事件 | 结果 |
|------|------|------|
| 2月 | 保加利亚列车（中车） | 中企退出 |
| 4月 | 罗马尼亚110MW光伏（隆基+上海电气） | 两家退出 |
| 4月 | 中国风电供应商五国调查 | Dawn Raids突袭 |
| 12月 | Temu都柏林 | 扣押设备 |

**三个事实：**
- 2024年全部深入调查 → 都是中国公司
- CRRC所有政府合同被算成"补贴" → €75亿
- 保加利亚案回复期限 → 只有**3天**

中国商务部2025年1月结论：FSR **构成贸易投资壁垒**。

**光伏关税同步打击：**
2025年6月23日起对中国光伏组件征临时关税
欧盟占中国组件出口23%（~65GW）→ 预计跌15-20%

⚠️ 不只是规则问题——是事实上的选择性执法。

## 正文

**CBAM（碳边境调节机制）** 2026年1月1日起正式收费。

组件本身不直接纳管，但**铝边框、钢支架、玻璃**都在覆盖范围。
按€80/吨碳价算：每GW组件碳关税 **600-1000万元**。

2025年9月，欧洲太阳能制造委员会(ESMC)正式推动把光伏成品纳入CBAM。
如果通过，整个组件出口成本将大幅跳升。

---

**CRMA（关键原材料法案）** 是欧盟的"脱中"路线图。

**关键数字：**
→ 中国控制全球稀土精炼 90%+
→ 中国加工全球锂 60%
→ 欧盟93%风电永磁体来自中国

**欧盟目标（2030年）：**
本土开采10% | 本土加工40% | 本土回收15% | 单一依赖≤65%

2025年12月推出 RESourceEU：€30亿资金，2026年起关键矿产**储备**。
中国也在反制：2025年4月限制7种稀土出口，11月扩至锂电池材料。

**中欧供应链脱钩在加速。**

## 正文

2026年5月，欧盟把逆变器限制从光伏风电扩展到了**储能PCS（储能变流器）**。

欧洲投资银行(EIB)、欧洲投资基金(EIF)等**核心融资渠道不得为使用中国PCS的项目提供资金**。

影响范围：中国2025年海外储能订单欧洲约61.82 GWh 面临排除风险。

---

**头部企业已经动起来了👇**

| 企业 | 基地 | 产能 | 进度 |
|------|------|------|------|
| CATL | 匈牙利+西班牙 | 100+50GWh | 一期2025底，二期暂停 |
| BYD | 匈牙利（整车） | 50万辆/年 | 电池厂尚未决策 |
| EVE | 匈牙利 | 28GWh | 2026/2027 |
| Gotion | 德国+斯洛伐克 | ~20GWh | 运营中 |
| CALB | 葡萄牙 | 15GWh | €20亿，2027/2028 |

---

**但风险也在累积👇**

① IAA 3年后电芯须欧盟原产 → 中国电芯厂必须在欧投产
② Northvolt 破产（2025.3）→ 欧洲电池自主梦碎
③ 匈牙利电池产量 -51%（2024.12）→ 需求放缓
④ IAA 强制技术转让 → 建厂的代价

💡 **CATL投了73亿欧元，可能还不够。**
因为IAA要求 **电芯厂也必须是欧盟原产**，而现在欧盟本土电芯产能几乎为零。

# 笔记 9/10：应对策略 —— 五条路

```
│                         │

│  3. 🔑 技术授权+主导权   │
│  4. 🌍 市场多元化        │
│  5. 📋 合规前置布局      │
│                         │
│  ⏰ 窗口期：2027年前      │
└─────────────────────────┘
```

## 正文

面对七重壁垒，企业可以走这五条路👇

**策略一 🏭 本地化建厂**
→ 匈牙利/东欧建厂，本地化率从30-50%起步
→ 利用豁免：成本>25%可申请
→ 考虑FTA缔约国（韩国/英国/土耳其）设厂 → 视同欧盟原产

**策略二 🌱 碳合规先行**
→ **立即**按欧盟PEF方法论收集数据（不用中国标准！）
→ 重签电力PPA，满足额外性+时空匹配
→ 上区块链溯源（Catena-X兼容）
→ 预约欧盟CAB机构预审

**策略三 🔑 技术授权 + 运营主导权**
→ 以财务投资人参与，保留关键运营主导权
→ 合资持股≤49%，但协议保留上游采购+技术迭代决定权
→ 核心技术分类管理，严格限制前沿技术授权

**策略四 🌍 市场多元化**
→ 东南亚/中东/拉美/非洲/中亚
→ 利用"一带一路"产能合作

**策略五 📋 合规前置**
→ 建全维度风险预警（地缘/价格/产能/交付/库存）
→ 协议加法律稳定性条款+不可抗力+退出机制
→ 供应商合同加ESG合规条款

⏰ **窗口期在2027年前。**
