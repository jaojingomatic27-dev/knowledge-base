## 二、岗位职责 — 能力需求拆解

### 1. 商务开发能力
- DACH 区域储能业务渠道开发及营销
- 对区域收入、利润和订单目标负责（**P&L 责任**——说明要背业绩数字）
- 面向公用事业（Utility）、电力投资商（IPP）、EPC 及开发商的市场策略执行

**→ 需要的能力**：GTM（Go-to-Market）策略制定、商务谈判、P&L 管控、德语区能源电力行业渠道资源

### 2. 客户关系管理能力
- 拓展及维护战略合作伙伴及重点客户关系
- 支持复杂项目的商务结构设计、定价策略及合同谈判
- 完整销售周期管理（从项目机会到合同签署）

**→ 需要的能力**：大客户管理（KAM）、复杂 B2B 销售、合同谈判法务意识、长期关系维护

### 3. 技术理解能力
- 将销售策略与**电网法规、市场机制及产品路线图**对齐
- 负责市场分析、竞品分析，并向研发及管理层反馈

**→ 需要的能力**：DACH 电网规范（VDE、电网并网流程）、欧洲辅助服务市场机制（FCR/aFRR/mFRR、容量市场）、储能产品技术理解（PCS/BESS/EMS）

## 四、核心能力画像

从这份 JD 可以看出，盛弘德国在找的**不是一个普通销售**，而是一个：

### 复合型高级人才画像

```
┌─────────────────────────────────────────────────┐
│            德语区储能销售经理 (DACH)              │
├─────────────────────────────────────────────────┤
│  50% 商务能力    │ 大客户开发、P&L管理、合同谈判   │
│  30% 技术能力    │ PCS/EMS/中压系统、电网法规     │
│  20% 行业人脉    │ 德语区能源高层客户资源          │
├─────────────────────────────────────────────────┤
│  关键门槛：                                       │
│  • 完整BESS项目从0到签约的操盘经验                 │
│  • 卖过PCS/中压系统（不是组件、不是电池、是PCS）    │
│  • 懂德国电网并网流程（VDE 4105/4110/4120等）     │
│  • 有Utility/IPP的C-level关系                     │
└─────────────────────────────────────────────────┘
```

### 这种人在市场上有多稀缺？

- 德语区有储能销售经验 + 技术背景的人，整个市场可能不超过 **200-300 人**
- 同时满足"卖过PCS/中压系统"和"有德语区电网并网实操经验"的，大概率集中在 SMA、Siemens、ABB、KACO、Fronius 等几家
- 盛弘作为中国公司，还要叠加"愿意加入中国企业"的意愿筛选——薪酬/职业发展吸引力不够的话，很难挖到这种人

### 盛弘德国分公司的现状推断（从 JD 反推）

1. **德国子公司刚起步** — 2024年成立，PCS 销售经理是第一波市场开拓角色
2. **还在0→1阶段** — 要找的人要"从市场进入到项目签约的完整 BESS 经验"，意味着不是接手存量客户，是自己开拓
3. **本地化程度尚浅** — 如果德国团队已经有成熟的售前技术/方案工程师，JD 不会把 EMS/SCADA/Modbus/IEC 协议写进销售岗位要求

## 六、总结

盛弘德国子公司（2024年成立，杜塞尔多夫）正在寻找一个**几乎"全能"的储能销售经理**——既要懂技术（PCS+EMS+电网协议）、又要有人脉（德语区能源高管关系）、还要能背业绩（P&L责任）。这类人才在德语区极度稀缺，JD 反映了盛弘在德国的**0→1 攻坚阶段**。

公开渠道未找到德国分公司的员工/客户负面评价——但这主要是因为公司太新、规模太小，而非"口碑好到无人批评"。随着 IAA 推动本地化，盛弘德国团队规模和本地化深度将是关键观察指标。
