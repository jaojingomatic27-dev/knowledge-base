# 中国储能PCS逆变器出口德国 — 认证全指南

> **日期**: 2026年6月16日
> **适用产品**: 大型储能/商用储能 PCS 逆变器（>135kW 中高压为主）
> **目标市场**: 德国 / 欧盟

---

## 一、认证总览（必须 vs 推荐）

### 1.1 必须认证（缺一个都进不了德国市场）

| 层级 | 认证/标准 | 适用说明 | 强制性 |
|------|----------|---------|--------|
| **基础安全** | CE-LVD (2014/35/EU) | EN 62477-1（储能逆变器安全）/ EN 62109-1/-2（光伏逆变器安全） | ✅ 强制 |
| **电磁兼容** | CE-EMC (2014/30/EU) | EN 61000-6-1/-3、EN 55011、EN 61000-3-2/-12（谐波电流） | ✅ 强制 |
| **有害物质** | RoHS (2011/65/EU) | EN 50581，限制铅/镉/汞等 10 项 | ✅ 强制 |
| **化学品** | REACH (EC 1907/2006) | SVHC 高关注物质管控 | ✅ 强制 |
| **低压并网** | VDE-AR-N 4105:2018 | 低压 <135kW 并网（工商业场景） | ✅ 强制（低压） |
| **中压并网** | VDE-AR-N 4110 | 中压 >135kW 并网（大型储能主力标准） | ✅ 强制（中压） |
| **高压并网** | VDE-AR-N 4120 | 高压 >110kV 并网（超大型电站） | ✅ 强制（高压） |
| **欧洲并网基础** | EN 50549-1/-2/-10 | 低压/中压并网 + 测试程序，德国也以此为基础 | ✅ 强制（并网产品） |

> ⚠️ **关键提示**: CE 认证 ≠ 并网许可。CE 让你能进海关，VDE 并网证书让你能把设备接上德国电网——两个缺一不可。

### 1.2 推荐认证（不是法律强制，但客户会要求）

| 认证/标准 | 适用场景 | 推荐程度 |
|----------|---------|---------|
| **IEC 62619 / IEC 63056** | 储能电池安全（若 PCS 带电池集成出货） | ⭐⭐⭐⭐⭐ |
| **VDE 2510-50** | 电池储能系统功能安全（德国市场极看重） | ⭐⭐⭐⭐ |
| **ErP 2019/1782** | 能效要求，欧洲效率 + 空载功耗，提升竞标竞争力 | ⭐⭐⭐⭐ |
| **IEC 60730 附录H** | BMS 功能安全 / PCS 控制安全 | ⭐⭐⭐ |
| **IEC 61508 / ISO 13849** | 系统功能安全等级（H 级功能安全），大项目常要求 | ⭐⭐⭐ |
| **C5 防腐 / IP66 防护** | 户外/沿海/工业环境，德国项目招标常设门槛 | ⭐⭐⭐ |
| **热蔓延测试** | 电池热失控安全验证（含电池的系统） | ⭐⭐⭐ |

### 1.3 最新动态（2025 年）

- **VDE-AR-N 4110 2023 年修订版**：135kW–950kW 的中压设备可使用**简化认证流程**（Anlagenzertifikat C），不再需要完整的全套证书。这对中国中型 PCS 是重大利好。
- **VDE-AR-N 4105 补充条款**（2025年6月1日生效）：>30kVA 设备须确保电网断开点随时可触及。

## 二、可以在中国做 vs 必须在德国做

| 认证项目 | 在哪里可以做 | 详情 |
|----------|------------|------|
| **CE-LVD** | ✅ 中国 | TÜV 南德/莱茵/北德中国实验室均可，含广州/上海/深圳 |
| **CE-EMC** | ✅ 中国 | 同上，中国 EMC 实验室资质完全覆盖 |
| **RoHS / REACH** | ✅ 中国 | 化学检测，中国实验室完全覆盖 |
| **EN 50549-1/-2/-10** | ✅ 中国 | TÜV 南德/莱茵/北德/SGS 国内均可完成 |
| **VDE-AR-N 4105（低压）** | ✅ 中国 | TÜV 莱茵中国 CBTL 实验室、安博检测等均可 |
| **VDE-AR-N 4110/4120（中高压）** | ✅ 中国 | TÜV 南德广州 6MW 平台可完成 TR3→TR4→TR8 全流程并发 DAkkS 证 |
| **ZEREZ 注册** | 🔶 德国电网运营商系统 | 必须通过德国 ZEREZ 平台（zerez.net）注册，可远程操作 |
| **电网运营商现场验收** | 🔴 德国现场 | 电站并网前，当地电网运营商（DSO）派人到场验收——这不是实验室测试，是项目交付环节 |

**关键结论：所有实验室测试/认证环节都可以在中国完成。** 唯一必须在德国做的事是 ZEREZ 在线注册 + 项目现场的电网运营商验收——这两个不是"认证"，是"并网流程"。

## 三、中国做 vs 德国做 — 推荐选择及原理

### 3.1 强烈推荐在中国做

| 原因 | 详细解释 |
|------|---------|
| **成本低 50–70%** | 德国 TÜV 工程师人工费是中国 3–5 倍，差旅另算。全套 VDE 4110 在德国做约 €8–12 万，在中国约 €3–5 万 |
| **沟通效率** | 中文母语沟通 + 硬件整改可以当场改、当场复测。在德国做，翻译+时差+邮寄样品来回一个月很正常 |
| **TÜV 中国实验室已有 DAkkS 资质** | 德国国家认可委员会（DAkkS）已授权 TÜV 南德广州等中国实验室直接发德国认证证书——法律效力与德国本土实验室完全等同 |
| **样板先行优势** | 盛弘、禾望、恩玖都已在 TÜV 南德广州完成 VDE 4110/4120 取证，路径成熟 |

### 3.2 为什么德国实验室仍然存在？

> **原理：（DAkkS 认可）=（德国法律效力）**

DAkkS（Deutsche Akkreditierungsstelle）是德国的国家认可机构。一个实验室只要通过了 DAkkS 的 ISO/IEC 17025 认可，无论这个实验室开在广州、上海还是慕尼黑，它出具的测试报告在德国法律上完全等效。

**TÜV 南德广州测试中心就是 DAkkS 认可的实验室**——6MW 双向测试平台，覆盖 TR3（实测）→ TR4（建模验证）→ TR8（发证）全流程。盛弘 1725kW PCS 就是在这里拿的 VDE 4110/4120 证书。

### 3.3 必须在德国做的环节

| 环节 | 为什么不能在中国做 |
|------|-------------------|
| **ZEREZ 注册** | 这是德国电网运营商联合会的官方数据库平台，只有德国域内认证渠道，物理上不存在境外入口。但这是线上的，不需要人过去 |
| **当地电网运营商现场验收** | 每个 DSO（如 E.ON、EnBW、Stadtwerke）在自己的服务区有验收权，必须派人到电站现场。这是项目 EPC 负责的，不是逆变器厂家的责任 |

## 四、认证路径建议（务实路线图）

### 阶段一：实验室认证（全部在中国，6–8 个月）

```
第1步: CE 基础包（LVD + EMC + RoHS + REACH）
       → TÜV 南德或莱茵中国实验室，2–3 个月
       费用: 约 ¥15–25 万

第2步: 欧洲并网基础（EN 50549-1/-2/-10）
       → 与 CE 同步做，同一家机构，1–2 个月
       费用: 约 ¥8–12 万

第3步: 德国并网（VDE 4105 或 4110，看功率）
       → 中压大机走 VDE 4110，TÜV 南德广州全流程
       注意: 135–950kW 可以用简化流程
       费用: 约 ¥20–35 万（全套 TR3+TR4+TR8）

第4步: 推荐项（提升竞争力）
       → VDE 2510-50 / ErP / IEC 62619 / 防腐防护
       按需选择，每项 ¥5–10 万
```

### 阶段二：注册 + 市场准入（1–2 个月）

```
第5步: ZEREZ 注册
       → 拿证书后在 zerez.net 注册产品
       可远程操作

第6步: 德国代理商/子公司备案
       → 需要有德国注册实体作为市场准入主体
```

### 总计

| 项目 | 最低配置 | 最佳配置 |
|------|---------|---------|
| **时间** | 8–10 个月 | 10–14 个月 |
| **费用** | ¥40–55 万 | ¥60–90 万 |
| **涉及机构** | 1 家（TÜV 南德或莱茵） | 1–2 家 |
| **出差德国** | 0 次 | 0–1 次（客户拜访非认证必需） |

## 六、常见误区

| 误区 | 真相 |
|------|------|
| ❌ CE 拿了就能并网 | ❌ CE ≠ 并网许可。VDE 并网 + EN 50549 是独立流程 |
| ❌ 必须去德国做认证 | ❌ TÜV 中国实验室有 DAkkS 资质，法律等效 |
| ❌ 中国绿证可以抵扣碳足迹 | ❌ 欧盟不认中国 GEC，要实体 PPA + 小时级匹配 |
| ❌ 认证一次永久有效 | ❌ 标准会更新（VDE 4105 2025 年有新补充条款），需持续维护 |
| ❌ 电池和 PCS 一起认证就行 | ❌ PCS 和电池的认证标准不同，分别做 |
